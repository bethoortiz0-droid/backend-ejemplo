Backend Ejemplo

Una API REST de tareas simulada directamente en tu navegador. Cada acción genera una petición HTTP de ejemplo y su respuesta JSON.

Endpoints

  • GET/api/tareas
  • POST/api/tareas
  • PUT/api/tareas/:id
  • DELETE/api/tareas/:id
